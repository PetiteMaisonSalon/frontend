# Petite Maison – Frontend

Website des Friseursalons Petite Maison, Hamburg.

## Design

- **Farben:** Grün (#4A5D4A), Beige (#E8E4DF), Braun (#5C4033), Akzente: Pink (#D4A5A5), Orange (#C9A86C) – ohne Blau und Rot
- **Typografie:** Cormorant Garamond (Überschriften), Geist (Fließtext)
- **Stil:** Kreativ, minimalistisch, elegant, reduziert
