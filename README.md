# Petite Maison – Frontend

Website des Friseursalons Petite Maison, Hamburg.

## Design

- **Farben:** Grün (#4A5D4A), Beige (#E8E4DF), Braun (#5C4033), Akzente: Pink (#D4A5A5), Orange (#C9A86C) – ohne Blau und Rot
- **Typografie:** Cormorant Garamond (Überschriften), Geist (Fließtext)
- **Stil:** Kreativ, minimalistisch, elegant, reduziert

## Seiten

| Route | Beschreibung |
|-------|--------------|
| `/` | Startseite – Hero, Philosophie, Termine-CTA |
| `/salon` | Unser Salon, Leistungen, Team (Mehtap, Sevim, Maria), Aveda, Termine |
| `/leistungen` | Leistungsbereiche inkl. Bestseller (Stännen/Highlights) |
| `/aveda` | Aveda-Partnerschaft und Philosophie |
| `/kontakt` | Kontaktdaten, Öffnungszeiten, Buchungshinweise |
| `/impressum`, `/disclaimer`, `/datenschutz` | Platzhalter für rechtliche Seiten |

## Entwicklung

```bash
npm install
npm run dev
```

Öffne [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
